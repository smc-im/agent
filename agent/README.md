# PHYS·LAB — 大学物理 3D 智能实验助教

一个**完全在本地文件夹内运行**的大学物理实验学习智能体。用自然语言描述需求，智能体会解析实验意图、调度 Three.js 三维渲染、生成可旋转/可调参的实验场景，并同步给出原理公式、误差分析、思考题拆解和可分享的预览链接。

> 预览地址（本地服务）：**http://127.0.0.1:8899/**
>
> 首次使用或服务停止后，双击 **`start.bat`** 即可重新启动。

---

## 1. 快速开始

### 方式一：当前已启动的服务
直接打开：

```
http://127.0.0.1:8899/
```

### 方式二：重新启动
双击本文件夹中的 `start.bat`。脚本会：

1. 以 `127.0.0.1:8899` 启动一个只读静态文件服务；
2. 自动打开浏览器；
3. 所有资源均来自本文件夹，不上传任何数据。

停止服务：关闭标题为 `PHYS-LAB Server` 的最小化命令行窗口，或在启动窗口按 `Ctrl+C`。

> 如果 8899 端口被占用，可修改 `start.bat` 中的 `PORT`，同时把 README 与界面里的预览地址端口改掉。

### 3D 模型与 PhET 的关系

PhET 是本项目在**实验选择、现象设计和可视化表达**上的重要参考，但 PhET 现有 HTML5 模拟以二维交互为主，并不提供可直接下载的 Three.js 三维模型。因此：

- 9 个三维场景均由本项目使用 **Three.js 在本地重构**，不是对 PhET 模型的搬运；
- 每个实验的「原理讲解」底部和左侧「PhET 资源映射」中都给出了最接近的 PhET 中文页面；
- 对 PhET 没有同名模拟的**迈克尔逊干涉仪**与**科里奥利力**，采用“最接近资源 + 本地 3D 补足”的方式处理，界面中有明确说明。

### 2.1 三个“深度实验”与评委演示线

9 个实验全部保留；其中 3 个被配置为**精密测量深度实验**，在左侧实验库中带「深度」标记，并拥有专用测量任务、数据表、拟合、不确定度、随堂预测/检测和评委演示脚本：

| 深度实验 | 测量任务 | 拟合目标 | 评委演示线 |
|---|---|---|---|
| 迈克尔逊干涉仪 | 条纹计数法测激光波长 | N–d 斜率 → λ | 光学 · 测出激光波长 |
| 光电效应 | 遏止电压法测普朗克常量 | Uₛ–ν 斜率 → h/e → h | 量子 · 测出普朗克常量 |
| 卡文迪许实验 | 扭秤偏角法测万有引力常量 | θ–M 斜率 → G | 引力 · 称量地球 |

点击右上角 **「评委演示」**，可以任选一条演示线。演示会：

1. 打开对应 3D 场景；
2. 先让学生做一次预测；
3. 生成 5 组可复现的测量数据；
4. 自动拟合并给出不确定度；
5. 做一道迁移检测，识别并记录误区；
6. 打开「学习看板」，展示实验覆盖、工具调用、知识命中、测量记录、答题正确率与误区分布。

## 3. 智能体能做什么

### 3.1 自然语言生成场景

在底部控制台输入，例如：

- `画出迈克尔逊干涉仪结构，标出分光板位置`
- `演示科里奥利力在地球自转中的效果`
- `打开光电效应，把波长调到 300 纳米`
- `把双缝间距调到 0.35 毫米`
- `把重力改成月球`

智能体会走一条可视化的任务流：

```
语义解析 → 场景规划 → 3D 渲染 → 教学编排
```

并在右侧同步生成：原理、核心公式、实时读数、误差来源、思考题、3D 元件注解。

### 3.2 实时调参

右侧「参数调节」中的每个滑块/下拉框都会同步影响：

- 三维几何与动画；
- 物理读数与公式结果；
- 地址栏中的预览参数；
- 可分享的预览链接。

例如：

- 迈克尔逊：改变动镜位移，观察圆环从中心冒出/陷入；
- 双缝：增大缝距，观察条纹变密；
- 科里奥利：把纬度改为 0°，观察偏转趋近于零；
- 单摆：把重力改成月球，观察周期变长；
- 光电效应：更换阴极材料，观察截止波长变化；
- 法拉第：增加线圈匝数，观察检流计摆幅增大。

### 3.3 答疑、误差与思考题

右侧「答疑」支持自然语言追问，例如：

- `为什么 M1 移动 λ/2 条纹就移动一条？`
- `为什么赤道上没有科里奥利偏转？`
- `为什么光强不改变遏止电压？`
- `误差主要来自哪里？`
- `这道思考题怎么理解？`

也可以直接点击 3D 场景中的元件标签，查看该元件的作用。

### 3.4 预览链接

点击右上角 **「生成预览链接」**，会得到形如：

```
http://127.0.0.1:8899/?sim=double-slit&lambda=600&d=0.4&L=2.5
```

的地址。链接包含：

- 当前实验 `sim`；
- 当前全部参数（波长、缝距、纬度、电压等）。

打开链接会自动恢复同一组三维场景、相机初始视角和教学面板。链接是本地地址，分享给同一台机器上的浏览器即可使用。

---

### 3.5 测量工作台

右侧新增 **「测量」** 标签页，包含：

- 当前实验的测量任务说明；
- 记录当前数据、生成 5 组示例数据；
- 可滚动数据表（动镜位移、条纹数、波长、频率、遏止电压、质量、偏角等）；
- 线性拟合、R²、斜率标准误与不确定度传播；
- 随堂「先预测」与「再检测」；
- 复制 CSV、打印实验报告（可另存为 PDF）。

三个深度实验的拟合结果示例：

- 迈克尔逊：λ ≈ 634 nm，u(λ) ≈ 4 nm；
- 光电效应：h ≈ 6.67×10⁻³⁴ J·s，W ≈ 2.16 eV；
- 卡文迪许：G ≈ 6.63×10⁻¹¹ N·m²/kg²。

> 演示数据包含少量读数抖动，用于让拟合和不确定度更真实；真实操作时按当前场景读数记录。

### 3.6 智能体工具轨迹

右侧底部 **AGENT TRACE** 可以查看每次操作对应的工具调用：

```text
intent.parse → knowledge.search → scene.build → physics.validate
→ scene.set_param → measurement.record → quiz.evaluate → teaching.compose
```

轨迹面板会显示工具调用次数、RAG 命中次数、物理校验次数和测量记录数，并展示最近一次检索到的知识片段。这不是一段预设动画，而是实际运行的工具链记录。

当前运行的是**本地规划器 + 检索增强 + 确定性物理工具**；工具层可以替换为 LLM Planner，而物理计算仍由确定性代码完成，避免模型编造数值。

### 3.7 学习看板

右上角柱状图图标打开 **学习看板**：

- 实验覆盖 `n/9`；
- 工具调用、知识命中、测量记录；
- 答题正确率；
- 实验使用分布；
- 常见误区排行；
- 最近学习事件时间线。

数据保存在本机 `localStorage`，不上传云端；「载入演示数据」用于评委展示完整班级画像，「清空本机数据」恢复真实会话。

## 6. 智能体的实现说明

### 6.1 本地语义解析

`assets/js/agent.js` 中的 `Agent` 负责：

- **实验匹配**：基于实验名、英文名与关键词加权评分；
- **意图识别**：生成、调参、原理、误差、思考题、分享、拆解、全屏等；
- **参数抽取**：识别 `550 nm`、`0.35 mm`、`35 度`、`-2 V`、`6 匝` 等单位；
- **相对调参**：支持“调大波长”“把间距调小”；
- **上下文**：未指定实验时默认使用当前场景。

这是一个**本地规则增强语义引擎**，不依赖云端大模型，因此可以离线运行、响应稳定、可解释。若需要接入在线 LLM，可在 `Agent.reply()` 前替换解析层，保留 `runBuild()` / `applyParams()` 两个动作接口即可。

### 6.2 场景调度

`App` 负责：

- 销毁旧场景、创建新场景；
- 更新教学面板、参数列表、快捷参数；
- 同步 URL 与分享链接；
- 管理加载层和任务流状态。

### 6.3 教学知识库

`knowledge.js` 为每个实验提供：

- 导入讲解；
- 核心公式；
- 关键机制；
- 误差来源与改进；
- 思考题与参考答案；
- 3D 元件注解；
- 追问关键词。

## 7. 科学说明与演示放大

这是一个教学演示应用，部分跨尺度量做了可视化处理，界面和讲解中会明确标注：

| 实验 | 真实计算 | 可视化处理 |
|---|---|---|
| 迈克尔逊 | 光程差、干涉级次、条纹位移 | 光学元件尺寸与镜面间距为教学比例；条纹图样按真实相位生成 |
| 科里奥利 | `f=2Ω sinφ`、真实横向加速度 | 轨迹横向偏转按“现象视觉放大”放大；切平面被抬离地表以便观察 |
| 双缝 | `Δy=λL/d`、单缝包络 | 缝距与波长比例为示意，条纹间距按真实公式计算 |
| 单摆 | 完整 `θ̈=-(g/L)sinθ-bθ̇`，RK4 积分 | 几何为真实米级比例 |
| 光电效应 | `E=hc/λ-W`、`eUₛ=E` | 电子数量/速度为示意 |
| 法拉第 | `ε=-N dΦ/dt` | 磁场用平滑模型近似，检流计为示意表头 |

因此：

- **公式与读数**用于定量学习；
- **三维画面**用于建立物理直觉；
- 不要用画面中的像素距离直接反推真实物理量。

## 8. 常见问题

**Q：页面空白 / 3D 场景无法初始化？**  
A：确认使用最新版 Chrome 或 Edge，并在设置中开启硬件加速。若仍然失败，打开开发者工具查看 WebGL 是否被禁用。

**Q：预览链接打不开？**  
A：链接由 `127.0.0.1:8899` 的本地服务提供。请确认 `start.bat` 的服务器窗口仍在运行；换端口后需要同步修改链接端口。

**Q：参数改了但画面没变化？**  
A：先确认右侧「参数调节」已经切到当前实验；改变参数后三维场景会立即重算。如果画面停住，点击右上角准星重置视角，或刷新页面。

**Q：为什么科里奥利力的轨迹看起来很大？**  
A：真实地球自转造成的短距离偏转极小。场景按「现象视觉放大」参数放大横向偏转，但右侧的 `f`、`a_C` 读数使用真实地球角速度计算。讲解中对此有说明。

**Q：为什么 PhET 里找不到同款 3D 模型？**  
A：PhET 目前主要提供二维 HTML5 交互模拟，没有可直接下载的 Three.js 3D 模型。本项目以 PhET 为教学参考，自行完成 3D 重构，并在每个实验底部给出对应的 PhET 中文资源。

## 9. 技术栈

- 原生 HTML / CSS / JavaScript（无构建步骤）
- Three.js r128（本地 `vendor/`）
- OrbitControls（本地 `vendor/`）

- 本地规则语义引擎
- 本地 RAG：中文 bigram + IDF 检索
- 确定性物理工具 + 物理校验器
- localStorage 学习档案与测量数据
- 线性拟合 / 不确定度传播 / 打印实验报告
